## 4. Why there is no Tauri job

`apps/desktop/src-tauri/src/licence.rs` and `creds.rs` round-trip through the **real OS keychain** —
`licence.rs`'s own test comment says it restores whatever was there before it ran, so a developer's
key survives `cargo test`. A headless runner has no keychain service, so that job would fail for a
reason that says nothing about the code, and a red job nobody believes is worse than no job.

Its TypeScript half **is** covered: `pnpm -r build` runs `tsc && vite build` for `apps/desktop`,
which is the part that actually breaks.

**Not claimed:** that `cargo clippy` or the 17 Rust tests pass anywhere but Prathamesh's machine.

- [x] **`migrations/versions/a643d2aa1586_create_users_table.py`** — 7 errors auto-fixed
      (`UP035`, `I001`, `UP007`×3) plus formatting. Not touched by PR #7, so no conflict.

- [x] **`app/api/routes/health.py`** — reformatted. Not in PR #7's diff.
- [ ] ⚠️ **`app/config.py` and `tests/fixtures/keys_fake.py` are still unformatted, on purpose.**
      Both are modified by PR #7. Reformatting them now buys a cosmetic win and pays for it in
      merge conflicts on a 176-file PR.

**`ruff format --check` is therefore NOT in CI.** `services/signal-data` would fail it on **91 of
120 files** — formatting has never been enforced in this repo, and turning it on is a
whole-repo reformat that earns its own commit, not a line slipped into a CI file. `ruff check`
(the lint rules) **is** enforced, and both projects pass it today.
